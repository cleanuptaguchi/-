# 勤怠管理LIFFアプリ セットアップ手順

## 1. スプレッドシートを準備する
1. 新規スプレッドシートを作成する
2. シートを2枚作り、名前を次の通りにする
   - `打刻ログ`：A列から「タイムスタンプ / userId / 氏名 / 種別 / 現場名」の見出しを入れる
   - `スタッフマスタ`：A列から「userId / 氏名 / 時給 / 雇用形態 / 所属現場」の見出しを入れる
3. URLの `/d/` と `/edit` の間の文字列（スプレッドシートID）を控えておく

## 2. GASプロジェクトを作る
1. スプレッドシートのメニューから「拡張機能」→「Apps Script」を開く
2. `Code.gs` の中身をこのファイルの内容に置き換える
3. 冒頭の `SHEET_ID` を、手順1で控えたスプレッドシートIDに書き換える
4. 「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」を選択
   - 実行するユーザー：自分
   - アクセスできるユーザー：全員
5. デプロイ後に発行される「ウェブアプリのURL」を控えておく（`https://script.google.com/macros/s/xxxx/exec`）

## 3. LINE Developersでチャネルを準備する
1. LINE Developersコンソールで「Messaging API」チャネルを作成する（無料）
2. 同じプロバイダー配下で「LIFF」アプリを追加する
   - エンドポイントURL：後述のLIFF用ページを公開したURL
   - サイズ：Full を推奨
3. 発行された「LIFF ID」を控えておく

## 4. LIFF画面(index.html)を公開する
`index.html` はどこかのWebサーバーで公開する必要があります（LINEのLIFFはURLを開く仕組みのため）。
0円で完結させる場合の選択肢:
- GAS自体を `doGet` でこのHTMLを返すようにし、GASのWebアプリURLをそのままLIFFのエンドポイントにする
- または GitHub Pages（無料）でホストする

`index.html` 冒頭の設定値を書き換える:
- `GAS_WEB_APP_URL`：手順2で控えたウェブアプリURL
- `LIFF_ID`：手順3で控えたLIFF ID

## 5. リッチメニューに「勤怠」ボタンを設置する
LINE公式アカウントのリッチメニュー設定で、ボタンのアクションを「LIFF画面を開く」に設定し、
手順3で作成したLIFFのURL（`https://liff.line.me/{LIFF ID}`）を指定する。

## 動作確認の流れ
1. リッチメニューの「勤怠」ボタンをタップ
2. LIFF画面が開き、現在のステータスが表示される
3. 「出勤する」→「休憩に入る」→「休憩から戻る」→「退勤する」の順にボタンを押し、
   スプレッドシートの `打刻ログ` シートに1行ずつ追記されることを確認する
